How the lessons are arranged

Every language follows the same order: the home row first, then the top row, then the bottom row, then the Shift letters. English continues with numbers, punctuation, common words, speed and accuracy. Hindi ends with the conjunct letters and Punjabi with the addak and the letters written at the foot.

Take the lessons in order. Each drill uses mostly the keys taught so far, so skipping ahead means typing keys you have not learnt. Stay on a lesson until its last two drill lines come out without looking and with hardly a mistake. For most people that is one to three short sessions per lesson.

How to practise a lesson

  1. Read the lesson and look at the keyboard chart. Note which finger types each new key.
  2. Place your fingers on the home row and type the first drill line slowly.
  3. Open the practice tool with the button at the end of the lesson. It shows the drill, marks each word right or wrong and highlights the next key on a keyboard.
  4. Repeat the drill until your accuracy is 95 per cent or better.
  5. Finish the session with a one minute typing test.

English first, or straight to Hindi or Punjabi?

The fingers rest on the same keys in all three languages. If you will need English as well, learn it first, because the letters printed on the keys help at the start. If you need only Hindi or only Punjabi, you can begin with that language directly. Its first lesson explains the finger positions from the beginning.

About the Hindi and Punjabi lessons

They teach the InScript layout, the standard for Indian scripts and the one built into Windows. Some typing tests use other layouts. If you are preparing for a test, read its notice to see which layout it allows before you choose what to learn. The guides on Hindi and Punjabi keyboard layouts explain the differences.
