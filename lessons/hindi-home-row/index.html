Hindi InScript: the home row

InScript is the standard keyboard layout for Hindi and other Indian scripts. It is the Hindi layout that comes with Windows and other systems, and it works with any Unicode font such as Mangal or Nirmala UI. This lesson teaches its middle row.

You do not need a Hindi keyboard installed to practise here. The practice tool can turn your English keys into InScript letters. To type Hindi in other programs, see the guide on adding a Hindi keyboard.

How InScript is arranged

The layout follows the logic of the script, which makes it easier to learn than it looks.

  • Left hand: vowels and matras. The key alone types the matra (the vowel sign). The same key with Shift types the full vowel.
  • Right hand: consonants. The key alone types the plain consonant. With Shift it types the aspirated partner, for example क alone and ख with Shift.

Because a Hindi syllable is usually a consonant followed by a matra, the hands tend to alternate: right, left, right, left. That is comfortable and fast.

The home row

Fingers rest on the same keys as in English typing: left hand on A S D F, right hand on J K L ;. Feel the bumps on F and J.

Type the consonant first, then the matra

Hindi is typed in the order it is spoken, not the order it looks on paper. For कि, type क and then ि, although the sign ि is drawn before the letter. The computer places it correctly. So कि is K then F, and के is K then S.

The halant joins letters

The key D types the halant ्, which removes the inherent "a" sound of a consonant and joins it to the next one. To type क्क, type क, then ्, then क. To type त्र, type त, ्, र. You will use this key constantly, which is why it sits under a strong finger on the home row.

Drill

Every word below uses only home row keys without Shift.

रक पक टक रट टप कप चक तर

कि के को कु पि पे पो पु

रोक टोक चोर पेट रेत केक

चुप तुक पुर किट टिक चित

पत्र चक्र टक्कर पक्के कच्चे

रोक टोक कर चुप, पेट पर तकरार

चोर को रोक कर पत्र पर टिक

What to watch

  • Keep the English home position. The only change is what the keys type.
  • The matras ि and ु are both typed by the left index finger, as F and G are in English.
  • If a matra appears alone with a dotted circle, you typed it before a consonant. Delete it and type the consonant first.

When these words come out without looking, go on to the top row, which adds ा, ी and many more consonants.
